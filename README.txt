OLD WEB ESSAY ARCHIVE
======================

1. Upload all files in this folder to your GitHub repository.
2. Make sure index.html is in the repository's main/root folder.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
4. Your site will receive a github.io address.
5. Edit index.html to change the archive list.
6. Edit essay-01.html, essay-02.html, etc. to add your essays.
7. For comments, create a public GitHub repository with Discussions enabled,
   then use https://giscus.app/ to generate the comment embed code and paste it
   into each essay page where the comments section is.

You can rename the site, colours and text in style.css and the HTML files.
